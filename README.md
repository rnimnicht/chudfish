# chudfish

Naive betting market arbitrage strategy

Polymarket had just introduced 15-min Crypto markets, and the liquidity was very low, so there was a small window of free arb. Likely could have made ~15/hr for about a month, but got sidetracked by an MTG Regional Championship.

Deployed to EC2 via Github Actions with MongoDB backing database.
